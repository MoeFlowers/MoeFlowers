# Moisés Flores

**Full-stack engineer in Venezuela (UTC−4).** I build business web apps, APIs, and automations for recurring work.

Since January 2026, I've worked remotely in the U.S. healthcare sector on internal applications, API integrations, and workflow automation. I graduated in Systems Engineering in August 2026.

- **Web apps:** React, Next.js, and TypeScript.
- **APIs and automation:** Node.js and Python for service integrations and recurring tasks.
- **Data and access:** SQL, PostgreSQL, data modeling, and access controls.
- **Testing:** Unit, integration, and end-to-end tests for data changes and user workflows.
- **Also:** Mobile apps and interactive 3D for the web.
